# Upstream sources and licensing

This bundle contains source code supplied by the user from third-party repositories.
Before redistributing or publishing the resulting combined repository, preserve each
upstream repository's license and required notices.

Do not assume that "open source" means all code can be relicensed as David AI code.

Review each upstream repository's LICENSE/NOTICE files before commercial redistribution.
The `vendor/` directories intentionally preserve upstream source structure as much as possible.

The David-specific Intelligence Fabric code in this bundle is separate from upstream source.
