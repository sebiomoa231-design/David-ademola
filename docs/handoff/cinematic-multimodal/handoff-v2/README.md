# DAVID AI — MASTER HANDOFF V2

This package is a consolidated technical handoff for the David AI Personal AI Operating System.

Purpose:
- give another AI a complete project history/specification;
- distinguish what is built, deployed, configured, missing, planned, and future;
- preserve architecture, features, provider roles, integrations, deployment state, memory architecture, AI Core, agent orchestration, and self-evolution plans.

Important:
1. This is a synthesized handoff, not a verbatim transcript of every chat message.
2. Secrets are intentionally NOT included.
3. Credential status is separated from provider existence.
4. Unknown/uncertain historical facts are marked instead of invented.
5. The existing David AI repository/backend must be treated as the source of truth for exact code structure and environment-variable names.
