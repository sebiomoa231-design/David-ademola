# DAVID AI — UPGRADE GOVERNANCE

David can evolve, but safety and owner control are permanent boundaries.

Suggested modes:
- OBSERVE_ONLY
- PROPOSE_ONLY
- ASSISTED
- CONTROLLED_AUTONOMOUS

High/critical changes should require explicit owner approval.

Protected capabilities should include:
- authentication/authorization
- secret handling
- owner identity/permissions
- audit logging
- rollback
- Evolution Engine safety policy
- destructive database operations
- production deployment policy

Every change should be:
- traceable
- testable
- reversible where practical
- auditable
- explainable
