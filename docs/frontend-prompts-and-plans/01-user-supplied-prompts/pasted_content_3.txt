This phase follows the previous David AI phases covering:

- backend architecture;

- frontend Command Center;
- production execution;

user control, and the existing production architecture.

- reason across projects;
- plan long-running objectives;
- adapt plans when reality changes;
- delegate work intelligently;
- coordinate specialist agents;
- reuse successful workflows;
- learn from completed tasks;

- monitor long-running work;

- distinguish facts from assumptions;
- recognize uncertainty;

- know when to continue autonomously;
- know when to pause for approval;
- know when a task is blocked;
- explain what it is doing;

- decisions;
- artifacts;
- research;
