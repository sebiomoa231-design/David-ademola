# David AI — Frontend Architecture

Frontend architecture/scaffold based on the David AI frontend product specification and the project discussions. This is the frontend side only; backend secrets are not included.

## Core UI
- Futuristic Personal AI Operating System shell
- Collapsible sidebar and responsive navigation
- Home dashboard
- David AI conversation workspace
- AI Core execution/progress visualization
- Memory & Personal Knowledge
- Projects and Tasks
- Agents
- Creative Suite
- Files / Assets
- Provider status
- Activity / Audit
- Settings / Integrations
- Voice interaction
- Mobile responsive experience

## Design
Deep-blue/dark foundation, sharp premium cards, holographic/HUD-inspired surfaces, restrained glow, strong hierarchy, responsive layouts.

## Integration
Use `NEXT_PUBLIC_API_URL`. Never put provider API keys in frontend code.
